# Number Guessing Game

A simple number guessing game built with Python using a "while" loop and basic error handling.

# About the Project

The program asks the user to guess a number between 0 and 100.

The correct number is 15.

The program continues asking for a guess until the user enters the correct number.

# Features

- Accepts numbers between 0 and 100
- Checks whether the guessed number is correct
- Shows an error message for numbers outside the valid range
- Handles non-numeric input using "try-except"
- Continues running until the correct number is guessed

# Concepts Used

This project uses:

- "while" loop
- "if / elif / else"
- "try / except"
- "int()"
- "input()"
- "break"
- "ValueError"

# How to Run

Make sure Python is installed, then run:

python guessing_game.py

 #How to Play

1. Enter a number between 0 and 100.
2. If the number is incorrect, try again.
3. If the number is outside the range, enter a valid number.
4. If you enter something that is not a number, the program will show an error.
5. Guess 15 to win! 🎉

 #Learning Purpose

This project was created as a beginner Python practice project to understand:

- Conditional statements
- User input
